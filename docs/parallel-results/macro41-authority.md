# Compiler-derived authority (#105)

This lane implements syntax identity registration and a separate post-check authority derivation. It reads the claim and `docs/rfcs/macro41-contracts.md` at `fd09dd7`, and incorporates the compiler audit: `World.calls` stores generic substitutions; actual call targets are `ir::Op::Call.callee`. No checker, IR, Forge host, or ordinary compiler behavior is changed.

`bind_source(&MacroSource, package, AuthorityLimits)` privately constructs `SourceBindings`. The sealed original syntax provides declaration identities, actual function headers, complete support ADTs/effects, global names, and source hash. This stage performs no semantic check and produces no graph or authority. Ordinary functions present in both syntax inventories are matched by actual name/span and header rather than double-registered. The registry reserves package 0 (`@vesper/builtin`) and uses package 1 for the one explicitly associated source package. Package strings are metadata, not provenance or a cross-package linker claim.

`derive(&CheckedSource, &SourceBindings, AuthorityLimits)` privately constructs `CheckedAuthorityBundle` only after the normal full-source check. It validates all actual current function/type/effect declarations against the original syntax identity mapping, guards current bodies/types, lowers the actual checked program, then derives static call edges and direct effect instances from actual IR. It independently reads `World.partial_ops` and `World.overflow_ops`, requiring every implicit marker to occur in current IR. The exact compiler wrapping_add/sub/mul whitelist is pure; unknown targets are refused. Static recursion uses graph edges rather than recursively expanding function bodies.

The original syntax hash and expanded checked hash intentionally differ. Bundle identity binds both via the SourceBindings identity, package, current graph contents and domain `vesper.forge.compiler-authority/1`. Equal textual headers never authorize reuse of an older graph. The integration lane remains responsible for proving that the checked candidate is the actual hygienic lowering of the resolved quotation and for gating contributed operations, including implicit arithmetic effects. This API accepts no caller-supplied World, graph, approved flag, deserialized snapshot, or substitute checked constructor.

Concrete generic effect instances inside ordinary monomorphic helpers are encoded per checked call-site substitution. Argument encoding is structural, tagged, package-qualified, and domain-separated (`vesper.forge.authority-type/1`), rather than Type Display text. Generic effect operations have no global union/first-instance node: direct macro-emitted uses are explicitly unsupported via `unsupported_emitted_def`. `Try`, closures, handlers, indirect/function-valued calls, generic functions/data, row arguments, operation-local generics, traits, models and elaborated contexts are unsupported. This is an intentionally conservative compiler bridge, not full-language or cross-package authority.

Public read-only APIs include `SourceBindings::{registry,core_name,kind,def_id,macro_def,source_package,source_hash,identity,global_names,effect_id}` and `CheckedAuthorityBundle::{graph,registry,checked_source_hash,bindings_identity,identity,unsupported_emitted_def}`. Both structs have private fields and no Clone/Deserialize constructors. AuthorityFailure distinguishes resource, unsupported, mapping, package, foreign source and unknown-definition failures.

Limits are positive bounded usize values with explicit refusal. Defaults / hard maxima: source 128 KiB / 1 MiB; definitions 512 / 2048; AST, IR and type nodes each 8192 / 32768; depth 48 / 64; cumulative metadata 2 MiB / 8 MiB; work 16 MiB / 64 MiB. Stage-one work/metadata use is carried into derive, without a fresh allowance. Before `ir::lower` clones, actual AST/types/body metadata are walked/counted and a conservative AST/binding/branch-based IR, copied-type and lexical-scope-map allowance is admitted. The scope allowance charges all bindings against all AST nodes using the observed maximum name length plus generated-slot overhead before lowerer scope snapshots. Serialization counts before fallible byte-vector reservation. Maxima need not be jointly attainable. These are conservative logical admission budgets, not exact RSS or latency proofs, and runtime recursion termination is not claimed.

Validation uses actual syntax dependency commits `3b14cdb65b46e105e6fb8a4af5f4bb6b4f188465` and `338c45ae5fc5d350845eb6c6600d3018c0d244d6`, temporarily copied with module registration. Root Forge dependency is temporarily registered with `default-features = false`; no registry version was changed. All temporary shared registrations/dependency files are restored before the owned commit.

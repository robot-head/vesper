# Typed Expr host (#104)

Compiled checkpoint implements a separate `typed_quote` API over the actual Vesper lexer. `Expr` is a grammar category, never successful type/effect/ownership checking. Private-construction source/input/slot/expansion/output/resolved-body wrappers carry per-host identity; even two hosts reusing a numeric SessionId cannot reinterpret one another's symbols. The source importer preserves original token ranges and source bytes. Existing untyped quotation/flat APIs remain compatible.

Templates parse InputSlot as an opaque Expr atom. Every substitution receives host-generated parentheses, preserves stored caller token origin/scopes, and is followed by a structural parse comparison against the substituted rich tree. Blocks retain actual statements and an optional tail, including empty/trailing-semicolon unit semantics. Source quotation compilation walks actual template bindings and validates global DefId claims from the macro definition environment before expansion; own initializers remain outside their new binding. Source macros are not enabled in existing batch commands by this crate.

Whole-body assembly resolves original bindings and every inserted expression together through the existing scope-set resolver. A minimal crate-private `resolve_preparsed` adapter accepts only this validated rich tree; legacy resolve still uses the unchanged old fragment parser. Public ResolvedBody getters expose the actual resolved fragment, richer ExprShape/ExprStatement tree, parallel source/generated provenance and original source. Generated reported spans remain display-only. No checked compiler artifact or authority graph is minted here.

One TypedBudget is shared across imports/templates/expansions/body resolutions. Logical source/token/text/scope/metadata/work caps preflight copies, repeated slot occurrences, generated grouping and resolver scopes. Counts use checked arithmetic; insufficient work exhausts the remaining allowance. Failed finish closes its expansion. A private liveness lease also prevents reuse after dropping or passing an expansion to a foreign host; abandoned arena data is swept before the next typed begin and otherwise owned until host destruction. Quotas do not claim RSS, allocator recovery or latency bounds. Unsupported operators, handlers, float/unary forms, binder/path slots and malformed kind/text claims fail explicitly.

# Checked intra-doc definition navigation

Claims189–191 and `docs/rfcs/docnav41-contracts.md` preceded writers after fresh
open-issue and actual external PR filename checks. Exclusive provider and actual
stdio worktrees preserve Claude's main/native/domain lanes and all pending
Forge/sourceDoc/Session/database paths. This draft stacks on doc-link PR184.

The existing definition request now falls back to checked intra-doc references
only after ordinary lexical navigation has no target. The current Index, strict
source/LineIndex association, URI/output bounds and original semantic guards run
unchanged. A private helper first requires an actual /// or //! lexer token, then
uses the same sealed source, original Module and borrowed actual World to derive
finite local descriptors and exact ORIGINAL declaration-name tokens. It reuses
the actual bounded doc-link parser, including exclusions and ambiguity behavior.

Supported targets are source functions/types/effects/trait names, explicit
inherent methods and effect operations. Real primitive-owner and unused Ghost
source methods navigate without inventing type declarations. Unsupported Self
and nonlocal tuple/function-type owners are excluded before inventory validation.
Builtin-only declarations and private generated Pact/model helpers are excluded.
No same-spelled parameter, body reference, string or another type's method can
supply a declaration target.

Selected unknown, ambiguous, unsupported or excluded references return null.
Successful occurrences still navigate when another link makes the parser report
Rejected: this does not mint an accepted Document, CheckedSource or proof artifact.
Returned Locations use the same current URI and existing strict UTF16 conversion.
Half-open hit ranges include brackets/backticks and exclude the final offset.

## Boundaries

No Session/database/sourceDoc/Forge/core/main/native/Cargo/build/workflow/wrapper
edit, public request/flag/Error variant, raised limit or hover change is needed.
The helper has an explicit1MiB metadata/16Mi logical-work stage and retains
existing navigation/link source, token, symbol, path and output bounds. It does
not retry a refusal with a fresh budget. Logical bounds are not latency/RSS
guarantees.

The server performs no URI filesystem read, cross-file guess, macro/component,
Lean or user-program execution. Normal original-source parsing/checking remains
authoritative; preview does not authorize navigation over original macros. These
are navigation facts, not current ownership or proof status. Package, generic,
Self, trait-method, variant and field reference paths remain outside the linked
profile. Hosted current-head checks remain pending; local Linux evidence does
not claim macOS/Windows or RBE execution. Claims remain reserved through merge.

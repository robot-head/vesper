Vesper Programming Language: Research Foundations, Language Design & Formal Specification
Executive Summary
Programming language scholarship across POPL, PLDI, ICFP, and OOPSLA (2025–2026) has converged on a clear post-Rust systems agenda: preserving zero-GC memory safety and data-race freedom while eliminating lifetime annotation noise, async function coloring, Pin self-referential boilerplate, and high formal verification overhead.


Vesper is a zero-GC systems programming language designed to be implemented in Rust (targeting Cranelift SSA IR and Lean 4 verification) that advances beyond Rust along three orthogonal axes:


1. Modal True Linearity (copy, affine, linear): Solves Rust's !Destruct and "Async Drop" gaps by guaranteeing exact-once consumption of linear obligations across all control-flow and error paths, paired with OxCaml-style automatic mode crossing.
2. One-Shot Lexical Effect Capabilities (eff): Unifies async I/O (io_uring), structured concurrency, checked fallibility (Fail), and custom allocators under stack-allocated, one-shot algebraic effect handlers—eliminating Pin, Future polling boilerplate, and colored higher-order combinators.
3. Second-Class Disjoint Place Projections (in, inout, sink): Replaces lifetime-annotated pointer types (&'a T, 'a mut T) with parameter passing modes and field-tree projections (inout broker.{index, metrics}), enabling alias-XOR-mutability without 'a lifetime soup.

2. Core Language Overview & How Vesper Improves on Rust
Rust's ownership system is affine (at-most-once), not linear (exactly-once): because mem::forget is safe and Drop::drop(&mut self) runs synchronously without returning errors or suspending, Rust cannot statically enforce that a database transaction is committed, an io_uring buffer is harvested, or an async socket is flushed before scope exit.
Three Pillars of Vesper
1. True linear Obligations (!Destruct Done Right):
Values default to Rust-like affine semantics (implicit scope-exit cleanup), while types marked linear cannot be implicitly dropped or forgotten. Every control-flow path—including early error propagation—must consume a linear value via explicit destructuring or a consuming transition (tx.commit() or tx.abort()). Cleanup becomes an ordinary consuming function that can perform I/O effects and return errors, eliminating the "Async Drop" problem. Using OxCaml-style mode crossing, generic wrappers (Option[T], Slice[T]) automatically inherit linear status only when instantiated with a linear payload.
2. One-Shot Lexical Effects Replace async, Pin, and Colored APIs:
Vesper unifies async suspension, structured concurrency, checked fallibility (Fail), and arena allocation as lexical effect capabilities (eff). Because handlers crossing linear or inout frames are restricted to one-shot resumptions, suspended stack frames never duplicate unique pointers—requiring zero Pin, zero Future state-machine polling boilerplate, and enabling effect-polymorphic higher-order combinators (items.map(f)).
3. Second-Class Place Projections (in, inout, sink) Eliminate 'a Soup:
Synthesizing Hylo's Mutable Value Semantics with Place Capability Graphs, borrows are second-class parameter modes rather than first-class lifetime-parameterized references. Functions declare disjoint field projections (inout broker.{index, metrics}), allowing callers to retain a shared in view of broker.config while mutating broker.index across helper calls with zero lifetime parameters.
Vesper by Example
// A `linear` type cannot go out of scope unconsumed; no implicit Drop or forget() exists.
linear struct WriteTxn {
    wal_slot: u64,
    dirty_pages: BufferPoolSlice,
}


impl WriteTxn {
    // Consumes `sink self` (ownership transfer), performing lexical `Storage` and `Fail` effects.
    // Solves Rust's "Async Drop" naturally: cleanup is an explicit effectful consumption!
    fn commit(sink self) -> CommitReceipt eff [Storage, Fail[IoError]] {
        let WriteTxn { wal_slot, dirty_pages } = self; // Linear destructuring discharges obligation
        Storage::flush_wal(wal_slot, in dirty_pages)?;
        Storage::release_slice(sink dirty_pages);
        CommitReceipt { wal_slot }
    }


    fn abort(sink self) eff [Storage] {
        let WriteTxn { wal_slot, dirty_pages } = self;
        Storage::discard_wal(wal_slot);
        Storage::release_slice(sink dirty_pages);
    }
}


// Disjoint place projection: mutates ONLY `broker.index` and `broker.metrics`,
// leaving `broker.config` freely readable by the caller without `'a` lifetime annotations.
fn append_batch(
    inout broker.{index, metrics}: Broker,
    in config: BrokerConfig,
    sink batch: RecordBatch,
) -> CommitReceipt eff [Storage, Fail[IoError]] {
    let tx: WriteTxn = Storage::begin_txn(config.max_batch_bytes);


    // If validation fails early, the compiler REJECTS returning via `?` unless `tx` is consumed!
    match validate_crc(in batch) {
        Ok(()) => {
            broker.index.insert_in_place(sink batch);
            broker.metrics.batches_written += 1;
            tx.commit() // `tx` linearly consumed on the happy path
        }
        Err(err) => {
            Storage::recycle_batch(sink batch);
            tx.abort(); // `tx` linearly consumed on the error path
            Fail::raise(err)
        }
    }
}
3. Formal Surface Grammar (LL(2) EBNF)
Vesper's surface syntax is engineered for deterministic LL(2) parsing into lossless rowan Red-Green Concrete Syntax Trees:


   1. Turbofish-Free Square-Bracket Generics: Type parameters and type arguments use [...] rather than <...>, while lexical rules separate UpperIdent (types, effects, variants) from LowerIdent (values, fields, lexical capability labels, effect row variables). Thus foo[WriteTxn](x) (generic instantiation call) vs. arr[idx](x) (slice index returning a closure) resolves in LL(2) without ::<T>.
   2. Disjoint Place Projection Trees: Parameters carry passing modes (in, inout, sink, defaulting to in) and field-tree selectors (inout broker.{index, metrics}).
   3. Resumption-Moded Effects: Effects declare whether handlers may abort (effect Fail[E], binding affine continuations) or must resume (linear effect Storage, binding linear continuations).


(* ==================== 1. MODULE & TOP-LEVEL ITEMS ==================== *)
Module        ::= Item* ;
Item          ::= StructDecl
                | EnumDecl
                | EffectDecl
                | FnDecl
                | ImplDecl ;


Mode          ::= 'copy' | 'affine' | 'linear' ;     (* default nominal floor: 'affine' *)


TypeParams    ::= '[' TypeParam ( ',' TypeParam )* ','? ']' ;
TypeParam     ::= UpperIdent ( ':' 'mod' Mode )?     (* modal kind bound, e.g. T: mod copy *)
                | LowerIdent ':' 'eff' ;             (* effect row variable *)


(* ==================== 2. DATA & EFFECT DECLARATIONS ================== *)
StructDecl    ::= Mode? 'struct' UpperIdent TypeParams? '{' FieldDeclList? '}' ;
FieldDeclList ::= FieldDecl ( ',' FieldDecl )* ','? ;
FieldDecl     ::= LowerIdent ':' Type ( '@@' Mode )? ; (* optional field modality override *)


EnumDecl      ::= Mode? 'enum' UpperIdent TypeParams? '{' VariantList? '}' ;
VariantList   ::= Variant ( ',' Variant )* ','? ;
Variant       ::= UpperIdent ( '(' TypeList? ')' | '{' FieldDeclList? '}' )? ;


(* 'linear effect' requires handlers to resume continuations exactly once;
   plain 'effect' permits handlers to resume at most once (abortable). *)
EffectDecl    ::= 'linear'? 'effect' UpperIdent TypeParams? '{' EffectOp* '}' ;
EffectOp      ::= 'fn' LowerIdent '(' ParamList? ')' ( '->' Type )? ';' ;


ImplDecl      ::= 'impl' TypeParams? Type '{' FnDecl* '}' ;


(* ==================== 3. FUNCTIONS & PLACE PROJECTIONS =============== *)
FnDecl        ::= 'fn' LowerIdent TypeParams? '(' ParamList? ')'
                  ( '->' Type )? EffClause? Block ;


ParamList     ::= Param ( ',' Param )* ','? ;
Param         ::= PassMode? 'self' ( '.' PlaceTree )?
                | PassMode? LowerIdent ( '.' PlaceTree )? ( ':' Type )? ;


PassMode      ::= 'in' | 'inout' | 'sink' ;          (* omitted PassMode defaults to 'in' *)


(* Disjoint field projection tree: e.g. broker.{index, metrics.counters} *)
PlaceTree     ::= LowerIdent ( '.' PlaceTree )?
                | '{' PlaceTree ( ',' PlaceTree )* ','? '}' ;


(* ==================== 4. TYPES & LEXICAL EFFECT ROWS ================= *)
Type          ::= FnType | BaseType ;
FnType        ::= 'fn' ( '@' Mode )? '(' ParamTypeList? ')' ( '->' Type )? EffClause? ;
ParamTypeList ::= ParamType ( ',' ParamType )* ','? ;
ParamType     ::= PassMode? Type ;


BaseType      ::= PrimType
                | '(' TypeList? ')'
                | UpperIdent TypeArgs? ;


TypeArgs      ::= '[' TypeArg ( ',' TypeArg )* ','? ']' ;
TypeArg       ::= Type | EffRow ;
TypeList      ::= Type ( ',' Type )* ','? ;
PrimType      ::= 'u8' | 'u32' | 'u64' | 'i64' | 'f64' | 'bool' | 'Unit' | 'Never' ;


EffClause     ::= 'eff' '[' EffRow? ']' ;
EffRow        ::= EffInst ( ',' EffInst )* ( '|' LowerIdent )?
                | LowerIdent ;
EffInst       ::= ( LowerIdent ':' )? UpperIdent TypeArgs? ; (* optional lexical cap label *)


(* ==================== 5. STATEMENTS, EXPRESSIONS & HANDLERS ========== *)
Block         ::= '{' Stmt* Expr? '}' ;
Stmt          ::= LetStmt | Expr ';' ;
LetStmt       ::= 'let' Pat ( ':' Type )? '=' Expr ';' ;


Expr          ::= HandleExpr
                | MatchExpr
                | IfExpr
                | ClosureExpr
                | AssignExpr ;


(* One-shot lexical handler with optional linear/affine state threading *)
HandleExpr    ::= 'handle' ( LowerIdent ':' )? UpperIdent TypeArgs?
                  ( 'state' Pat '=' Expr )?
                  'in' Block
                  'with' '{' ReturnClause ','? OpClause* '}' ;


ReturnClause  ::= 'return' Pat '=>' Expr ;
OpClause      ::= LowerIdent '(' PatList? ')' '=>' Expr ','? ;


MatchExpr     ::= 'match' Expr '{' ( Pat '=>' Expr ','? )* '}' ;
IfExpr        ::= 'if' Expr Block ( 'else' ( IfExpr | Block ) )? ;
ClosureExpr   ::= '|' ParamList? '|' ( '@' Mode )? ( '->' Type )? EffClause? Expr ;


AssignExpr    ::= BinaryExpr ( ( '=' | '+=' | '-=' ) BinaryExpr )? ;
BinaryExpr    ::= PostfixExpr ( BinOp PostfixExpr )* ;


PostfixExpr   ::= PrimaryExpr PostfixOp* ;
PostfixOp     ::= '(' ArgList? ')'                   (* value/effect call *)
                | '[' TypeList ']' '(' ArgList? ')'  (* LL(2) generic call: UpperIdent/Prim *)
                | '[' Expr ']'                       (* LL(2) slice index: LowerIdent/Lit *)
                | '.' LowerIdent                     (* field access / method receiver *)
                | '?' ;                              (* desugars to Fail::raise on Err *)


ArgList       ::= Arg ( ',' Arg )* ','? ;
Arg           ::= PassMode? Expr ;


PrimaryExpr   ::= Literal
                | LowerIdent
                | UpperIdent ( '::' LowerIdent | '{' FieldInitList? '}' )?
                | '(' ExprList? ')'
                | Block ;


FieldInitList ::= FieldInit ( ',' FieldInit )* ','? ;
FieldInit     ::= FieldNameOrShorthand ;
FieldNameOrShorthand ::= LowerIdent ( ':' Expr )? ;
ExprList      ::= Expr ( ',' Expr )* ','? ;


(* ==================== 6. PATTERNS & LEXICAL TOKENS =================== *)
Pat           ::= '_'
                | LowerIdent
                | UpperIdent ( '(' PatList? ')' | '{' FieldPatList? '}' )?
                | '(' PatList? ')'
                | Literal ;
PatList       ::= Pat ( ',' Pat )* ','? ;
FieldPatList  ::= FieldPat ( ',' FieldPat )* ','? ;
FieldPat      ::= LowerIdent ( ':' Pat )? ;


UpperIdent    ::= /[A-Z][A-Za-z0-9_]*/ ;
LowerIdent    ::= /[a-z_][A-Za-z0-9_]*/ ;
4. Core Calculus (λ_Vesper) & Modal Kind Lattice
Surface programs elaborate into λ_Vesper, where all effect invocations target an explicit lexical capability l, methods desugar into functions taking in/inout/sink place projections, and ? desugars into match + Fail::raise.
The Substructural Mode Lattice
Modes m ∈ {copy, affine, linear} form a bounded total lattice ordered by decreasing structural permission (copy ⊑ affine ⊑ linear):


Mode (m)
	Allowed Dynamic Uses U(m)
	Weakening (Implicit Drop)
	Contraction (Bitwise Alias/Copy)
	Composite Join (m ⊔ affine)
	copy (⊥)
	{0, 1, 2, ...} = N
	Permitted
	Permitted
	affine
	affine
	{0, 1}
	Permitted (runs sync cleanup)
	Forbidden
	affine
	linear (⊤)
	{1} (exact-once)
	Forbidden (must unpack/consume)
	Forbidden
	linear


Lattice join (⊔, maximum restriction) corresponds to intersection of permitted dynamic uses: U(m1 ⊔ m2) = U(m1) ∩ U(m2). Because {1} ⊂ {0, 1} ⊂ N, sub-moding is covariant along ⊑: a value available at mode m1 satisfies an expectation of m2 whenever m1 ⊑ m2 (e.g., passing a copy scalar or affine buffer to a linear consumer), whereas relaxing linear down to affine is unsound and forbidden unless justified by concrete modal kinding.
OxCaml-Style Modal Kinds & Mode Crossing
Every type τ carries a modal kind bound Δ ⊢ τ : mod m0, computing the strongest (lowest in ⊑) mode to which τ can safely strengthen based on its declared nominal floor m_decl and component types:


[K-Prim]
  scalar(τ)
  ──────────────────────
  Δ ⊢ τ : mod copy


[K-Var]
  (α : mod m) ∈ Δ
  ──────────────────────
  Δ ⊢ α : mod m


[K-Adt]
  decl(T[ᾱ]) = (m_decl, { f_i : τ_i @@ m_i })    ∀i, Δ ⊢ τ_i[σ̄/ᾱ] : mod k_i    ∀i, k_i ⊑ m_i (field modality well-formedness)
  ────────────────────────────────────────────────────────────────────────────
  Δ ⊢ T[σ̄] : mod (m_decl ⊔ ⊔_i (k_i ⊓ m_i))


[K-Fn]
  m ∈ {copy, affine, linear}
  ───────────────────────────
  Δ ⊢ (τ1 -[ε]@m-> τ2) : mod m

Field modality well-formedness (required by [K-Adt]): For every declared field f_i : τ_i @@ m_i, its component kind under the declaration's generic bounds must satisfy k_i ⊑ m_i. An override must never relax a component's ownership obligations. Therefore @@ copy accepts only components known to be copy, and @@ affine accepts only components known to be at most affine. Unannotated fields default to linear and satisfy this premise automatically. A copy wrapper containing a linear Ticket @@ copy is rejected; it cannot hide or discard the Ticket's obligation. This restriction preserves Theorem 2 (Total Linear Exhaustion).


Unannotated ADT fields default to m_i = linear (identity for meet: k_i ⊓ linear = k_i), whereas an explicit override like @@ copy caps that field's mode contribution. For copy enum Option[T] { None, Some(T) }, m_decl = copy, so [K-Adt] computes copy ⊔ k_T = k_T:


   * Option[u64] has kind mod copy (freely copied and dropped).
   * Option[BufferPoolSlice] has kind mod affine (droppable, non-copyable).
   * Option[WriteTxn] has kind mod linear (cannot go out of scope without matching Some(tx)).
5. Core Typing Judgments: Modal Linearity & Place Projections
Typing judgments have the shape:


Δ; Σ; Γ ⊢ e : τ @ m | ε

   * Δ (Kind & Row Context): Type variable modal bounds (α : mod m) and effect row variables (ρ : Row).
   * Σ (Lexical Capability Context): Scoped handler capabilities l : Cap_q[E], where q ∈ {affine, linear} is the effect's resumption guarantee.
   * Γ (Substructural Place Context): Owned bindings x :_m^own τ and second-class borrowed projections x :_m^μ τ (μ ∈ {shr, mut}).
   * ε (Lexical Effect Row): {l_1 : E_1^(q_1), ..., l_n : E_n^(q_n) | ρ}. The row resumption guarantee res(ε) ∈ {affine, linear} is defined as the meet ⊓_i q_i, with res(∅) = linear.
Discardability & Context Splitting (⊛)
   1. Discardability (discard(Γ)): Unused bindings at AST leaves may be implicitly dropped iff every binding is at most affine (∀ (x :_m^μ τ) ∈ Γ, m ⊑ affine). Active linear values and active mut borrows cannot be discarded.
   2. Context Split (Γ = Γ1 ⊛ Γ2): copy bindings contract into both sub-contexts; affine and linear owned bindings partition exclusively into either Γ1 or Γ2:


∅ = ∅ ⊛ ∅


Γ = Γ1 ⊛ Γ2
────────────────────────────────────────────────────────────
Γ, x :_copy^μ τ = (Γ1, x :_copy^μ τ) ⊛ (Γ2, x :_copy^μ τ)


Γ = Γ1 ⊛ Γ2    m ∈ {affine, linear}
────────────────────────────────────────────────────────────
Γ, x :_m^own τ = (Γ1, x :_m^own τ) ⊛ Γ2     (and symmetrically into Γ2)
Core Substructural & Mode-Crossing Rules
[T-Var]
  discard(Γ)
  ────────────────────────────────────
  Δ; Σ; Γ, x :_m^μ τ ⊢ x : τ @ m | ∅


[T-SubMode]
  Δ; Σ; Γ ⊢ e : τ @ m1 | ε    m1 ⊑ m2
  ────────────────────────────────────
  Δ; Σ; Γ ⊢ e : τ @ m2 | ε


[T-Cross]
  Δ; Σ; Γ ⊢ e : τ @ m | ε    Δ ⊢ τ : mod m0    m0 ⊑ m
  ─────────────────────────────────────────────────────
  Δ; Σ; Γ ⊢ e : τ @ m0 | ε


[T-Abs]
  Δ; Σ; Γ, x :_(m_x)^own τ1 ⊢ e : τ2 @ m2 | ε
  ∀ (z :_(m_z)^own τ_z) ∈ Γ,  m_z ⊑ m_fn      (no shr/mut borrows in Γ)
  ──────────────────────────────────────────────────────────────────────
  Δ; Σ; Γ ⊢ (λx : τ1. e) : (τ1 -[ε]@m_fn-> τ2) @ m_fn | ∅

   * [T-Cross] enforces OxCaml-style mode crossing: even when generic code yields a value at linear mode, if its concrete type τ satisfies Δ ⊢ τ : mod copy, it immediately strengthens down to copy.
   * [T-Abs] prevents second-class borrows (shr/mut) from escaping into closures and ensures any closure capturing a linear variable is itself linear (m_fn = linear, invoked exactly once).
Sequencing, Branching & The Resumption Frame Condition
[T-Let]
  Δ; Σ; Γ1 ⊢ e1 : τ1 @ m1 | ε1
  Δ; Σ; Γ2, x :_m1^own τ1 ⊢ e2 : τ2 @ m2 | ε2
  ∀ (z :_(m_z)^μ τ_z) ∈ Γ2,  m_z ⊑ res(ε1)          <-- Resumption Frame Condition
  ─────────────────────────────────────────────────────────────────────────────────
  Δ; Σ; Γ1 ⊛ Γ2 ⊢ (let x = e1 in e2) : τ2 @ m2 | ε1 ∪ ε2


[T-Match]
  Δ; Σ; Γ0 ⊢ e0 : T[σ̄] @ m0 | ε0
  ∀i,  Δ; Σ; Γ, x̄_ij :_(m0 ⊔ k_ij)^own τ_ij ⊢ e_i : τ @ m | ε
  ─────────────────────────────────────────────────────────────────────────
  Δ; Σ; Γ0 ⊛ Γ ⊢ (match e0 { C_i(x̄_i) => e_i }) : τ @ m | ε0 ∪ ε

   * The Resumption Frame Condition (m_z ⊑ res(ε1) in [T-Let]):
   * When e1 is pure or performs only linear effect operations (res(ε1) = linear), m_z ⊑ linear holds for all modes, allowing live linear obligations in Γ2 to survive across Storage suspensions.
   * When e1 performs an abortable effect like Fail (res(ε1) = affine), m_z ⊑ affine rejects any live linear variable in Γ2 (linear ⊑ affine is false!). Thus linear obligations can never be silently dropped by an early ? unwind.
   * Uniform Arm Consumption ([T-Match]): Every match arm receives the exact same residual environment Γ, guaranteeing that every linear binding is consumed along 100% of branches. Unpacking a linear struct transfers obligations to its fields, where scalar fields (u64) immediately strengthen back to copy via [T-Cross].
Second-Class Disjoint Place Projections (in, inout, sink)
Let p = x.π denote a field-tree projection on root variable x, with p_i ⊥ p_j denoting field-tree disjointness (x_i ≠ x_j or π_i ∩ π_j = ∅):


[T-CallProj]
  Δ; Σ; Γ_f ⊢ f : ((μ̄_i τ̄_i) -[ε]@m_f-> τ_ret) @ m_f | ∅
  ∀ i ≠ j,  (p_i ⊥ p_j  ∨  μ_i = μ_j = in)
  Γ_args supplies owned capability for each μ_i = sink (consuming p_i)
  and reborrows ν_i >= μ_i for each μ_i ∈ {in, inout} (restoring p_i upon return)
  ──────────────────────────────────────────────────────────────────────────────
  Δ; Σ; Γ_f ⊛ Γ_args ⊢ f(μ̄_i p̄_i) : τ_ret @ linear | ε
6. One-Shot Lexical Effects & Metatheoretic Soundness
Effect Perform and Stateful Lexical Handler Rules
[T-Perform]
  (l : Cap_q[E]) ∈ Σ    (op : τ_arg -> τ_res) ∈ E
  Δ; Σ; Γ ⊢ e : τ_arg @ linear | ε
  ───────────────────────────────────────────────────────────
  Δ; Σ; Γ ⊢ perform l.op(e) : τ_res @ linear | ε ∪ {l : E^q}


[T-Handle]
  Δ; Σ; Γ_s ⊢ e_init : τ_s @ m_s | ε
  Δ; (Σ, l : Cap_q[E]); Γ_body ⊢ e_body : τ_b @ m_b | {l : E^q} ∪ ε
  ∀ (z :_(m_z)^μ τ_z) ∈ Γ_h,  m_z = copy
  Δ; Σ; Γ_h, x :_(m_b)^own τ_b, s :_(m_s)^own τ_s ⊢ e_ret : τ_out @ m_out | ε
  ∀ (op_i : τ_i -> σ_i) ∈ E:
    Δ; Σ; Γ_h, y :_linear^own τ_i, s :_(m_s)^own τ_s,
          k :_q^own ((σ_i, τ_s) -[ε]@q-> τ_out) ⊢ e_i : τ_out @ m_out | ε
  ──────────────────────────────────────────────────────────────────────────────
  Δ; Σ; Γ_s ⊛ Γ_body ⊛ Γ_h ⊢
    (handle l : E^q state s = e_init in e_body with {
       return(x, s) => e_ret,
       op_i(y, s, k) => e_i
     }) : τ_out @ m_out | ε

Three invariants in [T-Handle] guarantee soundness without garbage collection or Pin:


   1. Continuation Mode Matches q: Captured delimited continuations k carry mode q ∈ {affine, linear}—never copy!
   * For effect Fail[Err] (q = affine), k is affine: raise(err, s, k) => Err(err) drops k cleanly via discard.
   * For linear effect Storage (q = linear), k is linear: every handler clause must resume k once (either inline or by parking the linear fiber handle in an io_uring completion table).
   2. Multi-Invocation Safety via Linear State Threading: Because e_body may invoke op_i multiple times in a loop, ambient variables Γ_h captured directly by clauses must be copy, while unique/linear resources (such as an io_uring submission ring) thread safely through the explicit state parameter s :_(m_s) τ_s.
   3. Lexical Escape Prevention: The capability label l is scoped to e_body and discharged from ε; any closure capturing l carries l : E^q in its arrow type ([T-Abs]), preventing l from escaping its defining handle block.
Worked Derivation: Catching an Unconsumed WriteTxn Across ?
Consider why Vesper rejects an unguarded ? while a WriteTxn is live:


let tx: WriteTxn = Storage::begin_txn(max_bytes); // q(Storage) = linear
validate_crc(in batch)?;                          // performs Fail::raise; q(Fail) = affine
tx.commit()

   1. After let tx = ..., the environment holds tx :_linear^own WriteTxn.
   2. Desugaring validate_crc(in batch)?; tx.commit() yields let _ = e_crc in tx.commit(), where e_crc has effect row ε1 = { l_fail : Fail[IoError]^affine }.
   3. Context splitting (⊛) places tx :_linear^own WriteTxn into Γ2 because tx.commit() consumes it.
   4. [T-Let] checks the Resumption Frame Condition m_tx ⊑ res(ε1), which evaluates to linear ⊑ affine — FALSE. Typechecking fails with an actionable error explaining that tx would leak if validate_crc raises Fail.
   5. By contrast, inside WriteTxn::commit, calling Storage::flush_wal(...) while dirty_pages is live produces res(ε1) = linear, satisfying m ⊑ linear.
Metatheoretic Guarantees
Modeling types via step-indexed separation logic (Iris style) yields three core guarantees:


   * Theorem 1 (Type & Mode Preservation): Well-typed closed configurations step without stuck states while preserving types, lexical effect rows, and disjoint place capabilities.
   * Theorem 2 (Total Linear Exhaustion): In any closed program ∅; ∅; ∅ ⊢ e : τ @ copy | ∅ that terminates at value v, every dynamically constructed linear struct instance is unpacked by [T-Match] exactly once—never leaked on an early error edge and never duplicated across a continuation.
   * Corollary (Zero-Pin Stack Relocation): Because every continuation k has mode q >= affine (at-most-once resumption) and second-class in/inout projections cannot be stored as first-class pointers inside suspended locals, suspended fiber stacks contain no self-referential &'a borrows across yield points and can be relocated or pooled without Pin.
7. 5-Stage Rust Implementation Architecture
Implementing Vesper in Rust bypasses LLVM compile-time bottlenecks during development by lowering into Cranelift (cranelift_codegen) while supporting direct verification extraction to Lean 4:


   1. Resilient Lexing & Lossless CST (logos + rowan + salsa + ariadne):
Zero-copy SIMD-accelerated lexing (logos) feeds an LL(2) recursive-descent parser constructing a lossless rowan Red-Green CST, memoized inside salsa incremental queries for sub-millisecond LSP diagnostics.
   2. Bidirectional Mode & Effect Inference:
Lowers CST to HIR and runs bidirectional inference with OxCaml-style mode crossing ([T-Cross]), lexical effect row unification (eff [E1, E2 | r]), and resumption frame verification ([T-Let]).
   3. Place Capability Graph (PCG) Linearity & Borrow Checker (petgraph / polonius-engine):
Lowers HIR to basic-block Place IR and builds a Place Capability Graph over field trees (broker.index vs. broker.config) to verify:
      * Exclusivity: No active inout place overlaps any active in or inout place.
      * Linear Exhaustion: Every linear binding reaches an explicit destructuring or sink call on 100% of CFG paths (including Fail unwind edges).
      4. Effectful Equality Saturation (egglog):
Feeds Place IR into egglog using effect-token threading (Effectful E-Graphs, OOPSLA 2026) to perform evidence-passing specialization: statically known tail-resumptive handlers (like Fail or arena allocation) fuse directly into inline branches or pointer bumps with zero closure/coroutine allocation, while suspending linear handlers (io_uring) lower to lightweight segmented stack switches (wasmtime-fiber style).
      5. Dual Backend (cranelift-codegen + Lean 4 Verification Extractor):
         * Native Codegen & JIT: Emits Cranelift SSA IR (CLIF) to cranelift-codegen / cranelift-jit / cranelift-object for fast x86_64 and AArch64 machine code generation.
         * Lean 4 Proof Extraction: Because Vesper replaces unrestricted &'a mut pointer aliasing with second-class inout and sink value projections, a compact backend pass translates Vesper functions 1-to-1 into pure state-passing Lean 4 definitions (achieving Aeneas-grade verification without needing Charon lifetime reconstruction).

9. Formal SemVer Variance and Interface Subtyping Calculus (vesper semver)
Rather than trusting human-curated version numbers, Vesper Loom enforces Contextual Substitutability mathematically at publish and resolution time via vesper semver. Given a baseline .vhir package interface I_old and candidate upgrade I_new, I_new is Minor/Patch-compatible (I_new ≼_pub I_old) if and only if every well-typed downstream module C that satisfies modal linearity, disjoint place-projection borrowing, Resumption Frame Conditions, and Loom.toml capability ceilings against I_old remains well-typed—and preserves Theorem 2 (Total Linear Exhaustion) and No Authority Amplification—when linked against I_new without modifying C.
9.1 Substructural Mode, Effect-Row, and Place-Tree Subtyping
All signature compatibility rules reduce to four decidable partial orders over λ_Vesper:
                        1. Modal Value & Kind Ordering (m_new ⊑ m_old):
Recall copy ⊑ affine ⊑ linear. Because U(copy) = N, U(affine) = {0, 1}, and U(linear) = {1}, strengthening a produced value or ADT kind downward along ⊑ (for example, linear → affine or affine → copy) strictly expands what callers may do with the value while keeping all existing single-consumption code valid via [T-SubMode]. Conversely, moving upward (copy → affine or affine → linear) invalidates caller contractions, implicit drops (discard(Γ)), and [T-Let] Resumption Frame checks.
                        2. Lexical Effect-Row Subtyping (ε_new <: ε_old):
An upgraded effect row ε_new safely replaces ε_old when it neither introduces ungranted capabilities nor degrades continuation resumption guarantees:
[SV-EffRow]
  caps(ε_new) ⊆ caps(ε_old)      row_vars(ε_new) ⊆ row_vars(ε_old)
  res(ε_old) ⊑ res(ε_new)        (where affine ⊑ linear and res(∅) = linear)
  ──────────────────────────────────────────────────────────────────────────
  ε_new <: ε_old
                           * Why res(ε_old) ⊑ res(ε_new) is Required: In [T-Let], every live binding z held across a call e1 must satisfy m_z ⊑ res(ε1). Removing an abortable Fail effect raises res(ε) from affine to linear; by transitivity (m_z ⊑ affine ⊑ linear), all existing callers continue to typecheck. Adding an abortable effect drops res(ε) from linear to affine, breaking any caller holding a live linear resource across the call.
                           3. Disjoint Field-Tree Narrowing (π_new ⊆ π_old):
Let leaves(π) denote the set of leaf field paths selected by a projection tree π (with a bare root variable x denoting the full field tree ⊤_τ). Narrowing a borrowed projection (leaves(π_new) ⊆ leaves(π_old), such as inout self.{index, metrics} → inout self.{index}) preserves every caller's [T-CallProj] disjointness obligation p_i ⊥ p_j, because leaves(π_new) ∩ leaves(π_other) ⊆ leaves(π_old) ∩ leaves(π_other) = ∅.
                           4. Passing-Mode Invariance on Linear Consumption (μ_new ≡_pass μ_old):
                              * Changing sink → in or inout is Major-breaking whenever the parameter type can instantiate to linear: callers relied on sink to discharge their linear obligation, so leaving the argument unconsumed violates Total Linear Exhaustion at the call site.
                              * Changing in → inout or sink is Major-breaking: callers holding only shared in access or reusing an affine binding after the call can no longer satisfy [T-CallProj].
                              * Changing inout → in is Minor-safe only via explicit reborrow coercion when π_new ⊆ π_old; otherwise passing modes remain invariant while π narrows.
9.2 Declaration and Signature Compatibility Judgments
[SV-Fn]
  Δ_new = [ᾱ : mod m̄_bound_new]     Δ_old = [ᾱ : mod m̄_bound_old]
  ∀k,  m_bound_old_k ⊑ m_bound_new_k                (contravariant generic modal bounds)
  m_fn_new ⊑ m_fn_old                               (covariant closure/fn mode)
  ∀i,  π_i_new ⊆ π_i_old                            (narrowed field-tree borrow)
  ∀i,  (μ_i ∈ {in, sink} ⟹ Δ_old ⊢ τ_i_old <: τ_i_new)
     ∧ (μ_i = inout      ⟹ Δ_old ⊢ τ_i_new ≡ τ_i_old)  (mutable place invariance)
  Δ_old ⊢ τ_ret_new <: τ_ret_old    m_ret_new ⊑ m_ret_old
  ε_new <: ε_old
  ──────────────────────────────────────────────────────────────────────────────────────
  (fn @ m_fn_new [Δ_new] (μ̄ x̄.π̄_new : τ̄_new) -> τ_ret_new @ m_ret_new eff [ε_new])
    ≼_pub
  (fn @ m_fn_old [Δ_old] (μ̄ x̄.π̄_old : τ̄_old) -> τ_ret_old @ m_ret_old eff [ε_old])


[SV-Adt-Closed]
  vis(T) = closed_fields     Δ_old ⊢ k_T_new ⊑ k_T_old
  ────────────────────────────────────────────────────────────────────
  (m_new struct T[ᾱ] { private ... }) ≼_pub (m_old struct T[ᾱ] { private ... })


[SV-Enum-Open]
  open enum E[ᾱ]     variants(E_old) ⊆ variants(E_new)
  ∀ added V(τ̄_v) ∈ variants(E_new) \ variants(E_old),  Δ_old ⊢ k_(τ̄_v) ⊑ k_(E_old)
  ──────────────────────────────────────────────────────────────────────────────────
  E_new ≼_pub E_old


[SV-Effect-Decl]
  ops(E_new) = ops(E_old)     (sealed(E) ⟹ q_old ⊑ q_new)     (open(E) ⟹ q_new = q_old)
  ──────────────────────────────────────────────────────────────────────────────────────
  (q_new effect E) ≼_pub (q_old effect E)
Notice two critical soundness guardrails captured above:
                              5. Open Enum Modal Preservation ([SV-Enum-Open]): Adding a new variant CorruptWal(WriteTxn) carrying a linear payload to an existing affine open enum IoError is rejected as Major-breaking, because wildcard match arms _ => ... in downstream crates require k_IoError ⊑ affine to discard unknown variants safely.
                              6. Open vs. Sealed Effect Resumption Variance ([SV-Effect-Decl]): If downstream crates are permitted to write handle E blocks (open(E)), changing effect E (q = affine) to linear effect E (q = linear) is Major-breaking because existing third-party handler clauses that drop the continuation k fail [T-Handle]. Only sealed effects (handled exclusively inside the defining package) may strengthen q from affine to linear in a minor release.

10.2 Substructural Modes, Field Trees, and Lexical Effects (vesper-hir)
The core type/effect representation encodes the substructural lattice copy ⊑ affine ⊑ linear, resumption modes, and trie-structured disjoint field projections directly into compact value types:
// crates/vesper-hir/src/ty.rs
use la_arena::Idx;
use rustc_hash::FxHashMap;
use smol_str::SmolStr;


/// Substructural mode lattice ordered by `Copy < Affine < Linear` (`copy ⊑ affine ⊑ linear`).
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
#[repr(u8)]
pub enum Mode {
    Copy = 0,   // ⊥: weakening + contraction allowed
    Affine = 1, // implicit drop allowed; bitwise copy forbidden
    Linear = 2, // ⊤: exact-once consumption; neither drop nor copy allowed
}


impl Mode {
    /// Lattice join (`m1 ⊔ m2`): takes the stricter ownership obligation.
    #[inline]
    pub fn join(self, other: Self) -> Self {
        core::cmp::max(self, other)
    }


    /// Lattice meet (`m1 ⊓ m2`): takes the more permissive mode.
    #[inline]
    pub fn meet(self, other: Self) -> Self {
        core::cmp::min(self, other)
    }


    /// Predicate `discard(m)`: true iff `m ⊑ Mode::Affine`.
    #[inline]
    pub fn is_discardable(self) -> bool {
        self <= Self::Affine
    }
}


/// Continuation resumption contract `q ∈ {affine, linear}` on an effect declaration.
#[derive(Clone, Copy, Debug, PartialEq, Eq, PartialOrd, Ord, Hash)]
#[repr(u8)]
pub enum ResumptionMode {
    Affine = 1, // Handler may abort (e.g., `effect Fail[E]`)
    Linear = 2, // Handler must resume k exactly once (e.g., `linear effect Storage`)
}


impl ResumptionMode {
    #[inline]
    pub fn as_mode(self) -> Mode {
        match self {
            Self::Affine => Mode::Affine,
            Self::Linear => Mode::Linear,
        }
    }
}


/// Second-class parameter passing modes (`[T-CallProj]`).
#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub enum PassMode {
    In,    // Shared read-only projection (`shr`)
    InOut, // Exclusive mutable projection (`mut`)
    Sink,  // Ownership transfer / linear consumption (`own`)
}


#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub struct FieldIdx(pub u16);


/// Prefix tree representing disjoint field projections like `broker.{index, metrics.counters}`.
/// An empty `children` map represents a leaf selection covering the entire sub-place.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct FieldTree {
    pub children: FxHashMap<FieldIdx, FieldTree>,
}


impl FieldTree {
    pub fn whole_place() -> Self {
        Self { children: FxHashMap::default() }
    }


    /// Checks `π_1 ⊥ π_2`: true iff the two selector trees share zero overlapping leaf paths.
    pub fn is_disjoint(&self, other: &Self) -> bool {
        if self.children.is_empty() || other.children.is_empty() {
            return false; // One selects the entire sub-struct, overlapping anything beneath it
        }
        for (field, lhs_sub) in &self.children {
            if let Some(rhs_sub) = other.children.get(field) {
                if !lhs_sub.is_disjoint(rhs_sub) {
                    return false;
                }
            }
        }
        true
    }


    /// Checks `π_new ⊆ π_old` for `vesper semver` `[SV-Fn]` projection narrowing.
    pub fn is_subset_of(&self, older: &Self) -> bool {
        if older.children.is_empty() {
            return true; // `older` borrowed the entire sub-place
        }
        if self.children.is_empty() {
            return false; // `self` widens to the entire sub-place while `older` was partial
        }
        self.children.iter().all(|(f, sub)| {
            older.children.get(f).is_some_and(|old_sub| sub.is_subset_of(old_sub))
        })
    }
}


#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub struct EffectId(pub u32);


#[derive(Clone, Debug, PartialEq, Eq)]
pub struct EffectInst {
    pub cap_label: Option<SmolStr>,
    pub effect_id: EffectId,
    pub resumption: ResumptionMode,
    pub type_args: Vec<Idx<Ty>>,
}


/// Lexical effect row `eff [l1: E1^q1, ..., ln: En^qn | tail_var]`.
#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct EffectRow {
    pub instances: Vec<EffectInst>,
    pub tail_var: Option<u32>,
}


impl EffectRow {
    /// Computes `res(ε) = ⊓_i q_i`, with `res(∅) = Mode::Linear`.
    /// Note: unresolved `tail_var` conservatively bounds resumption via context Δ.
    pub fn resumption_guarantee(&self, tail_bound: Mode) -> Mode {
        self.instances
            .iter()
            .fold(tail_bound, |acc, inst| acc.meet(inst.resumption.as_mode()))
    }
}
10.3 Place IR and Place Capability Graph Checker (vesper-mir-pcg)
After bidirectional inference and OxCaml-style mode crossing ([T-Cross]), HIR lowers into PlaceIr. The PCG engine performs forward dataflow over basic blocks, checking both disjoint field borrowing and the Resumption Frame Condition across every effectful edge:
// crates/vesper-mir-pcg/src/pcg.rs
use rustc_hash::FxHashMap;
use vesper_hir::ty::{EffectRow, FieldIdx, FieldTree, Mode, PassMode};


#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub struct LocalId(pub u32);


#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub struct BlockId(pub u32);


#[derive(Clone, Debug, PartialEq, Eq)]
pub struct PlaceProjection {
    pub local: LocalId,
    pub tree: FieldTree,
}


#[derive(Clone, Debug)]
pub enum Statement {
    Assign { dst: LocalId, ty_mode: Mode },
    /// Linear struct/enum unpacking (`[T-Match]`), discharging `src` and initializing `fields`.
    UnpackLinear { src: LocalId, bound_locals: Vec<(LocalId, Mode)> },
    CallProj {
        args: Vec<(PassMode, PlaceProjection)>,
        ret_dst: LocalId,
        ret_mode: Mode,
        effects: EffectRow,
    },
}


#[derive(Clone, Debug)]
pub enum Terminator {
    Goto(BlockId),
    SwitchInt { discr: LocalId, targets: Vec<BlockId> },
    PerformEffect {
        effects: EffectRow,
        resume_target: BlockId,
        /// Populated when `res(effects) == Mode::Affine` (abortable handler unwind edge).
        abort_unwind: Option<BlockId>,
    },
    Return,
}


/// Per-local capability state in the Place Capability Graph lattice.
#[derive(Clone, Debug, PartialEq, Eq)]
pub enum LocalCapability {
    LiveOwned { mode: Mode, moved_subtrees: FieldTree },
    Consumed,
}


#[derive(Clone, Debug, PartialEq, Eq)]
pub enum PcgError {
    OverlappingProjection { local: LocalId },
    UnconsumedLinearAtScopeExit { local: LocalId },
    InconsistentLinearConsumptionAtJoin { block: BlockId, local: LocalId },
    ResumptionFrameViolation { live_linear: LocalId },
}


#[derive(Clone, Debug, Default, PartialEq, Eq)]
pub struct PcgState {
    pub locals: FxHashMap<LocalId, LocalCapability>,
}


impl PcgState {
    /// Enforces `[T-CallProj]` pairwise disjointness + `sink` linear consumption.
    pub fn check_call_projections(
        &mut self,
        args: &[(PassMode, PlaceProjection)],
        effects: &EffectRow,
    ) -> Result<(), PcgError> {
        // 1. Pairwise Alias-XOR-Mutability across all place arguments
        for (i, (m_i, p_i)) in args.iter().enumerate() {
            for (m_j, p_j) in &args[i + 1..] {
                let both_shared = matches!((m_i, m_j), (PassMode::In, PassMode::In));
                if !both_shared && p_i.local == p_j.local && !p_i.tree.is_disjoint(&p_j.tree) {
                    return Err(PcgError::OverlappingProjection { local: p_i.local });
                }
            }
        }


        // 2. Consume `sink` arguments first (so consumed linear values aren't flagged in frame check)
        for (pass_mode, proj) in args {
            if *pass_mode == PassMode::Sink {
                self.locals.insert(proj.local, LocalCapability::Consumed);
            }
        }


        // 3. Enforce `[T-Let]` Resumption Frame Condition: ∀ live z, m_z ⊑ res(ε)
        let res_guarantee = effects.resumption_guarantee(Mode::Linear);
        for (&local, cap) in &self.locals {
            if let LocalCapability::LiveOwned { mode, .. } = cap {
                if *mode > res_guarantee {
                    return Err(PcgError::ResumptionFrameViolation { live_linear: local });
                }
            }
        }
        Ok(())
    }


    /// Enforces uniform linear consumption across CFG join points (`[T-Match]` / `if-else`).
    pub fn join_at_block(&self, other: &Self, block: BlockId) -> Result<Self, PcgError> {
        let mut merged = self.locals.clone();
        for (&local, rhs_cap) in &other.locals {
            match (merged.get(&local), rhs_cap) {
                (Some(LocalCapability::LiveOwned { mode: Mode::Linear, .. }), LocalCapability::Consumed)
                | (Some(LocalCapability::Consumed), LocalCapability::LiveOwned { mode: Mode::Linear, .. }) => {
                    return Err(PcgError::InconsistentLinearConsumptionAtJoin { block, local });
                }
                (Some(LocalCapability::LiveOwned { mode, .. }), LocalCapability::Consumed)
                    if mode.is_discardable() =>
                {
                    // Implicit drop inserted on the live incoming edge for `affine` / `copy` local
                    merged.insert(local, LocalCapability::Consumed);
                }
                _ => {}
            }
        }
        Ok(Self { locals: merged })
    }


    /// Enforces `discard(Γ)` at function `Return`.
    pub fn check_return_exhaustion(&self) -> Result<(), PcgError> {
        for (&local, cap) in &self.locals {
            if let LocalCapability::LiveOwned { mode: Mode::Linear, .. } = cap {
                return Err(PcgError::UnconsumedLinearAtScopeExit { local });
            }
        }
        Ok(())
    }
}

    AuthorityAmplification {
        pkg: SmolStr,
        dep: SmolStr,
        escalated_effect: SmolStr,
    },
    ForbiddenUnsafeFfi { pkg: SmolStr },
}


impl CapabilityCeiling {
    /// Verifies the No Authority Amplification invariant across every dependency edge `P -> D`.
    pub fn verify_edge(
        &self,
        pkg_name: &SmolStr,
        dep_name: &SmolStr,
        dep_effective: &Self,

        if dep_effective.allow_unsafe_ffi && !self.allow_unsafe_ffi {

                return Err(ConfinementViolation::AuthorityAmplification {
                    pkg: pkg_name.clone(),
                    dep: dep_name.clone(),
                    escalated_effect: eff.clone(),
                });
            }
        }
        Ok(())
    }
}

11. The Lean 4 Functional Proof Extractor (vesper-verify-lean)
Memory safety and modal linearity prevent crashes, data races, and forgotten protocol obligations, yet critical systems components—WAL storage engines, consensus state machines, cryptographic codecs, and capability routers—still require mathematical proof of functional correctness. Recent Rust-to-Lean verification pipelines such as Charon + Aeneas and Hax (A Rust-to-Lean Verification Pipeline with AI Provers, CAV/AIMACS 2026) demonstrate that lifting systems code into pure functional Lean 4 enables practical verification backed by a small trusted kernel (itself verified in Lean4Lean, TYPES 2025). However, retrofitting functional extraction onto Rust faces three steep structural hurdles:
                              1. First-Class Mutable Reference Prophecy Overhead: Because Rust permits first-class mutable references (&'a mut T) stored inside structs and conditionally reborrowed across branches, Charon must reconstruct Low-Level Borrow Calculus (LLBC) lifetimes and Aeneas must synthesize complex backward prophecy functions to propagate mutations when region 'a expires.
                              2. Opaque Self-Referential Coroutines: Rust async state machines rely on self-referential Pin pointers and polling traits that functional extractors cannot directly lift without manual re-modeling.
                              3. Whole-Graph Re-Verification and Axiom Drift: Without native package-manager integration, Lean 4 proofs suffer from toolchain drift, bit-vector library collisions, and expensive re-checking of upstream dependencies.
vesper-verify-lean eliminates all three bottlenecks by exploiting Vesper's core invariants ([T-CallProj], [T-Let], and [T-Handle]) to perform a direct, zero-prophecy 1-to-1 functional translation from verified PlaceIr into pure Lean 4 definitions and composable .olean proof certificates.

	11.2 Formal Functional Translation Rules (PlaceIr to Lean 4)
Because vesper-hir and vesper-mir-pcg have already discharged modal linearity, alias-XOR-mutability, and lexical capability scoping, vesper-verify-lean erases ownership modes (copy, affine, linear) at the value level and translates types, disjoint projections, and effect rows purely structurally.
                              1. Scalar, BitVector, and ADT Erasure (⟦τ⟧):
                              * Fixed-Width Machine Scalars: u8, u32, u64, i64 map directly to Lean 4 core fixed-width types (UInt8, UInt32, UInt64, Int64) backed by BitVec, enabling Lean 4's built-in bv_decide (SAT-backed bit-blasting) and omega (linear integer arithmetic) tactics without external library collisions.
                              * Checked vs. Wrapping Arithmetic: Standard Vesper arithmetic (+, -, *) emits explicit overflow checks in the Fail[ArithOverflow] effect (or discharges bounds statically), while explicit wrapping intrinsics (wrapping_add) map directly to total UInt64.add.
                              * Modal ADT Erasure: Both affine struct and linear struct declarations lower to standard Lean 4 structure types, and enum declarations lower to inductive types (Never maps to Empty, Unit maps to Unit).
                              2. Disjoint Field-Tree Projections as Lawful Lenses (⟦inout x.π⟧):
For every non-trivial field-tree projection x.π (such as broker.{index, metrics}: Broker), the extractor synthesizes a pure projection bundle and auto-proves three @[simp] lens laws by rfl:
                                 * get_π : ⟦τ⟧ → ⟦τ_π⟧ (extracts the projected leaf fields into a tuple or slice record).
                                 * set_π : ⟦τ⟧ → ⟦τ_π⟧ → ⟦τ⟧ (functional record update replacing only leaves in π).
                                 * Auto-Generated @[simp] Frame Lemmas:
                                 * set_get_π (s : ⟦τ⟧) : set_π s (get_π s) = s := rfl
                                 * get_set_π (s : ⟦τ⟧) (v : ⟦τ_π⟧) : get_π (set_π s v) = v := rfl
                                 * Disjoint Frame Preservation (π_1 ⊥ π_2): For every sibling field or projection π_2 disjoint from π_1, get_π2 (set_π1 s v) = get_π2 s := rfl. When a caller holds in broker.config across append_batch(inout broker.{index, metrics}, ...), Lean's simp tactic proves (b.setIndexMetrics p).config = b.config in zero manual steps.
                                 3. Passing-Mode and Effect-Row Translation:
Given a Vesper function f with parameters (μ_1 p_1 : τ_1, ..., μ_n p_n : τ_n), let inout_indices be the ordered indices where μ_i = inout:
                                    * Pure Inputs: Every parameter (in, inout, and sink alike) passes its projected value v_i : ⟦τ_i⟧ as a pure Lean 4 function parameter.
                                    * Pure State-Tuple Return: f returns the product of its nominal return type and the updated values of all inout projections: RetTuple(f) := ⟦τ_ret⟧ × ∏_{j ∈ inout_indices} ⟦τ_j⟧.
                                    * Adaptive Effect Monad Wrapping: Rather than forcing monadic boilerplate onto pure code, vesper-verify-lean stratifies eff [ε] into three clean tiers:
                                    * Tier 0 — Pure (ε = ∅): Emits a bare, total Lean 4 function returning RetTuple(f).
                                    * Tier 1 — Fallible Only (ε = [Fail[E]]): Wraps the return in Lean's standard Except ⟦E⟧ RetTuple(f) with do-notation (? maps natively to Lean 4's monadic early-return).
                                    * Tier 2 — General One-Shot Lexical Effects (ε = [E_1^q1, ..., E_k^qk]): Wraps the return in a universe-polymorphic Freer Interaction-Tree Monad EffM ⟦ε⟧ RetTuple(f):

inductive StorageOp where
  | beginTxn     (maxBytes : UInt64)
  | flushWal     (slot : UInt64) (pages : BufferPoolSlice)
  | discardWal   (slot : UInt64)
  | releaseSlice (pages : BufferPoolSlice)
  | recycleBatch (batch : RecordBatch)


def WriteTxn.commit (self : WriteTxn) : EffM [StorageEff, FailEff IoError] CommitReceipt := do
  let { walSlot, dirtyPages } := self
  Storage.flushWal walSlot dirtyPages
  Storage.releaseSlice dirtyPages
  pure { walSlot }


def WriteTxn.abort (self : WriteTxn) : EffM [StorageEff] Unit := do
  let { walSlot, dirtyPages } := self
  Storage.discardWal walSlot
  Storage.releaseSlice dirtyPages


-- inout broker.{index, metrics} returns (CommitReceipt x BrokerIndexMetricsProj)
def appendBatch
    (brokerProj : BrokerIndexMetricsProj)
    (config     : BrokerConfig)
    (batch      : RecordBatch)
    : EffM [StorageEff, FailEff IoError] (CommitReceipt × BrokerIndexMetricsProj) := do
  let tx <- liftLinear (Storage.beginTxn config.maxBatchBytes)
  match validateCrc batch with
  | .ok () =>
    let index' := SegmentedIndex.insertInPlace brokerProj.index batch
    let written' <- checkedAddU64 brokerProj.batchesWritten 1
    let receipt <- WriteTxn.commit tx
    pure (receipt, { index := index', batchesWritten := written' })
  | .error err =>
    liftLinear (Storage.recycleBatch batch)
    liftLinear (WriteTxn.abort tx)
    Fail.raise err


end KrabkaWal

/// Stratified effect-row encoding avoiding monadic noise on pure functions.
pub fn wrap_return_with_effects(base_ret: LeanType, effects: &EffectRow) -> LeanType {
    if effects.instances.is_empty() && effects.tail_var.is_none() {
        return base_ret; // Tier 0: Pure total Lean 4 function
    }
    if effects.instances.len() == 1 && effects.instances[0].cap_label.as_deref() == Some("Fail") {
        // Tier 1: Specialized Except E Ret
        return LeanType::Except {
            err: Box::new(LeanType::Nominal { name: "IoError".into(), args: vec![] }),
            ok: Box::new(base_ret),
        };
    }
    // Tier 2: General one-shot Freer Interaction-Tree EffM
    let row_sig = effects
        .instances
        .iter()
        .map(|inst| inst.cap_label.clone().unwrap_or_else(|| "AnonEff".into()))
        .collect();
    LeanType::EffM { row_sig, ret: Box::new(base_ret) }
}


/// Translates a [T-CallProj] statement into pure value passing plus lawful lens writeback.
pub fn lower_call_proj(
    callee: &SmolStr,
    args: &[(PassMode, PlaceProjection, SmolStr)],
    ret_dst: SmolStr,
    effects: &EffectRow,
    continuation: LeanExpr,
) -> LeanExpr {
    let mut call_args = Vec::with_capacity(args.len());
    let mut inout_writebacks: Vec<(SmolStr, SmolStr, SmolStr)> = Vec::new();
    let mut bound_vars = vec![ret_dst.clone()];


    for (idx, (mode, proj, lens_stem)) in args.iter().enumerate() {
        let root_var = SmolStr::new_inline("x_local");
        let projected_arg = if proj.tree.children.is_empty() {
            LeanExpr::Var(root_var.clone())
        } else {
            LeanExpr::LensGet {
                base: Box::new(LeanExpr::Var(root_var.clone())),
                lens_fn: format!("get_{lens_stem}").into(),
            }
        };
        call_args.push(projected_arg);


        if *mode == PassMode::InOut {
            let out_tmp: SmolStr = format!("{ret_dst}_inout_{idx}").into();
            bound_vars.push(out_tmp.clone());
            inout_writebacks.push((root_var, format!("set_{lens_stem}").into(), out_tmp));
        }
    }


    let mut post_call = continuation;
    for (root_var, set_lens, out_tmp) in inout_writebacks.into_iter().rev() {
        post_call = LeanExpr::Let {
            pat: root_var.clone(),
            val: Box::new(LeanExpr::LensSet {
                base: Box::new(LeanExpr::Var(root_var)),
                lens_fn: set_lens,
                new_val: Box::new(LeanExpr::Var(out_tmp)),
            }),
            next: Box::new(post_call),
        };
    }


    let call_expr = Box::new(LeanExpr::App { func: callee.clone(), args: call_args });
    if effects.instances.is_empty() && effects.tail_var.is_none() {
        let pat: SmolStr = bound_vars.join(", ").into();
        LeanExpr::Let { pat, val: call_expr, next: Box::new(post_call) }
    } else {
        LeanExpr::DoBind { bound_vars, call: call_expr, next: Box::new(post_call) }
    }
}

/// Compiles .olean certificates and audits that zero sorryAx or unapproved axioms exist.
pub fn verify_and_audit_olean_bundle(
    lake_dir: &Path,
    exported_theorems: &[SmolStr],
    allow_classical: bool,
) -> Result<blake3::Hash, AxiomHygieneError> {
    let mut allowed: FxHashSet<&str> = FxHashSet::from_iter(["propext", "Quot.sound"]);
    if allow_classical {
        allowed.insert("Classical.choice");
    }


    let output = Command::new("lake")
        .arg("build")
        .current_dir(lake_dir)
        .output()
        .map_err(|e| AxiomHygieneError::LeanKernelFailed { stderr: e.to_string() })?;


    if !output.status.success() {
        return Err(AxiomHygieneError::LeanKernelFailed {
            stderr: String::from_utf8_lossy(&output.stderr).into_owned(),
        });
    }


    let audit_out = Command::new("lake")
        .args(["env", "vesper-lean-axiom-audit"])
        .args(exported_theorems.iter().map(|s| s.as_str()))
        .current_dir(lake_dir)
        .output()
        .map_err(|e| AxiomHygieneError::LeanKernelFailed { stderr: e.to_string() })?;


    let report = String::from_utf8_lossy(&audit_out.stdout);
    for line in report.lines() {
        // Line format is theorem_name:axiom_1,axiom_2
        if let Some((thm, axioms_csv)) = line.split_once(':') {
            for ax in axioms_csv.split(',').filter(|a| !a.is_empty()) {
                if ax == "sorryAx" {
                    return Err(AxiomHygieneError::SorryDetected { theorem: thm.into() });
                }
                if !allowed.contains(ax) {
                    return Err(AxiomHygieneError::UnauthorizedAxiom {
                        theorem: thm.into(),
                        axiom: ax.into(),
                    });
                }
            }
        }
    }


    let mut hasher = blake3::Hasher::new();
    hasher.update(report.as_bytes());
    Ok(hasher.finalize())
}

                                       7. Uncancellable Linear I/O Suspensions (q = linear): Because Net, Storage, Clock, and Async are linear effects, res(ε) = linear.                                        8. Explicit Cancellation Checkpoints (q = affine): Cancellation can unwind a fiber only at operations carrying Cancel in their effect row (Cancel::check(), Pulse::race, Pulse::timeout, or chan.recv_cancel()), where res(Cancel) = affine.

// Concurrent WAL commit and quorum replication with zero lifetimes, zero Arc, and static cancel safety
fn replicate_and_commit(
    inout broker.{index, metrics, repl_stream}: Broker,
    in config: BrokerConfig,
    sink batch: RecordBatch,
) -> CommitReceipt eff [Scope, Storage, Net, Clock, Cancel, Fail[BrokerError]] {
    // Cancellation permitted BEFORE acquiring linear obligations (res(Cancel) = affine):
    Cancel::check()?;


    let wire_slice = batch.as_wire_slice();
    let tx: WriteTxn = Storage::begin_txn(config.max_batch_bytes);


    let (wal_res, repl_res) = Pulse::scope(|inout s| eff [Scope, Storage, Net, Clock] {
        // Child Fiber 1 consumes linear `tx` on the Storage io_uring handler:
        let wal_join: JoinHandle[Result[CommitReceipt, IoError]] = s.spawn(|| eff [Storage] {
            handle Fail[IoError] in {
                Ok(tx.commit())
            } with {
                return r => r,
                raise(e) => Err(e),
            }
        });


        // Child Fiber 2 mutates ONLY `broker.repl_stream` while sharing `in wire_slice`:
        let net_join: JoinHandle[Result[Unit, IoError]] = s.spawn(|| eff [Net, Clock] {
            Net::write_all(inout broker.repl_stream, in wire_slice)
        });


        // Both linear JoinHandles MUST be joined before scope exit:
        (wal_join.join(), net_join.join())
    });


    let receipt = wal_res.map_err(BrokerError::Wal)?;
    let _unit   = repl_res.map_err(BrokerError::Replication)?;


    broker.index.insert_in_place(sink batch);
    broker.metrics.batches_written += 1;
    receipt
}
12.5 Cranelift Stack-Switching Fiber ABI and Evidence-Passing Lowering
vesper-opt-egglog (Stage 4) and vesper-codegen-clif (Stage 5) compile Pulse capabilities without state-machine bloat using a three-tier lowering strategy:
                                          12. Pinned Lexical Evidence Vector (r15 on x86_64 / x28 on AArch64):
Every effectful Vesper function receives a hidden Cranelift vmctx register pointing to the active EvidenceVector—a cache-line-aligned array of (handler_fn_ptr, state_ptr, parent_sp) slots indexed by static lexical capability depth in Σ. Looking up Storage, Net, or Fail is a single O(1) base+offset load with zero dynamic hash-map search.
                                          13. 0 ns Tail-Resumptive Fast Path (egglog Fusion):
When an effect operation completes synchronously (for example, Clock::now_ns(), Cancel::check() when uncancelled, or Net::read_some satisfied from an in-memory read buffer), egglog evidence-passing rewrite rules fuse the handler inline into a direct register check and branch—allocating zero continuations and performing zero stack switches.
                                          14. One-Shot Pooled Fiber Stack Switching (vesper_fiber_yield / vesper_fiber_resume):
When an io_uring SQE or contended channel must suspend:
                                             1. Each spawned fiber runs on a pooled virtual-memory stack slab (64 KiB default virtual reservation with 4 KiB lazy physical page faults and a hardware guard page, pooled per worker core).
                                             2. At suspension, vesper-codegen-clif emits a lightweight call to the naked assembly trampoline vesper_fiber_yield(ev_slot, op_tag, arg_ptr), which spills only callee-saved registers (rbx, rbp, r12–r15, rsp, rip on x86_64, or x19–x29, lr, sp, d8–d15 on AArch64—80 to 144 bytes total) into an intrusive FiberHeader at the top of the fiber stack, writes the FiberHeader pointer into sqe.user_data (as the linear continuation k), and swaps rsp/sp back to the worker thread's scheduler loop in ~4–6 ns.
                                             3. By Section 6's Zero-Pin Stack Relocation Corollary, suspended stacks hold zero first-class self-referential &'a borrows across yield points, allowing pooled stacks to recycle or relocate cleanly.

impl PulseWorkerShard {
    /// Schedules a resumed linear continuation `k` harvested from an `io_uring` CQE or `LinearTx`.
    #[inline]
    pub fn wake_linear_continuation(&mut self, k_fiber: NonNull<FiberHeader>) {
        if let Some(prev) = self.lifo_slot.replace(k_fiber) {
            self.run_queue.push_back(prev);
        }
    }


    /// Deterministic `SimPulse` step: pops the next runnable fiber according to a seeded PRNG choice.
    pub fn step_deterministic(&mut self, prng_choice: usize) -> Option<NonNull<FiberHeader>> {
        if let Some(hot) = self.lifo_slot.take() {
            self.run_queue.push_front(hot);
        }
        if self.run_queue.is_empty() {
            return None;
        }
        let idx = prng_choice % self.run_queue.len();
        self.run_queue.remove(idx)
    }
}

13. Vesper Bridge: Zero-Copy FFI, Omniglot Isolation, and Declarative Sys-Specs
Systems languages succeed or fail by how safely and cheaply they cross foreign boundaries—linking kernel rings (liburing), C codecs (liblz4, libzstd), network stacks (rdma-core), and zero-copy wire formats (Apache Arrow IPC, Kafka RecordBatch segments). In Rust, unsafe extern "C" disables static safety checks wholesale: a foreign C call can return invalid bit patterns (such as 2u8 for bool), retain borrowed pointers past return, alias mutable references, or corrupt host stack frames.
Grounded in Building Bridges: Safe Interactions with Foreign Languages through Omniglot (Schuermann, Toubes, Potyondy, Pannuto, Milano, and Levy, OSDI 2025 Best Paper), SafeFFI (Braunsdorf et al., USENIX Security 2026), Rage Against the State Machine / Abacus (Potyondy et al., ASPLOS 2026), and formal zero-copy layout typing (zerocopy, 2024–2026), Vesper Bridge (@vesper-std/ffi, implemented in crates/vesper-ffi) achieves zero-serialization cross-language interoperability while preserving Vesper's modal linearity, disjoint borrowing, and Loom supply-chain confinement.
13.1 Architectural Improvements Over Rust FFI
                                                   * Wire and DMA Struct Casting: Rust requires external zerocopy or bytemuck procedural macros or unsafe transmute, where implicit struct padding causes immediate undefined behavior. Vesper provides a built-in wire struct declaration enforcing zero implicit padding, explicit endian scalars (u32be, u64le), and 100% safe O(1) slice projection.
                                                   * Foreign Return Validity: Rust asserts valid host types on faith across extern "C", so an invalid C bool, enum discriminant, or misaligned pointer triggers immediate undefined behavior. Vesper Bridge adopts Omniglot's ForeignVal[T] (?T) wrapper: foreign returns carry zero validity assumptions until promoted via constant-time validate().
                                                   * Cross-Language Borrowing: Rust raw pointers (*const T, *mut T) lose borrow-checker tracking at the call boundary. Vesper's declarative .vsys specifications map nocapture C pointers directly onto [T-CallProj] in and inout slice projections.
                                                   * Foreign Handle Lifecycle: Rust manual Drop wrappers ignore close/flush errors and permit mem::forget leaks. Vesper's linear extern type enforces exact-once C finalizer execution or protocol state transitions across 100% of control-flow paths.
                                                   * Supply-Chain and Hardware Memory Isolation: Whereas any Rust crate can link C code via build.rs and corrupt process memory, Vesper gates foreign libraries via eff [Ffi[Lib]] in Loom.toml and supports 1.5 ns Hardware MPK/PKRU and Arm POE zero-copy sandboxing.
13.2 Zero-Copy wire struct Layouts and Endian-Safe Projections
To eliminate defensive memcpy calls and unsafe pointer casts when parsing network frames or kernel rings, Vesper introduces wire struct—a nominal layout-verified declaration kind (mod copy):
                                                   1. Zero Implicit Padding Invariant: The compiler computes exact byte offsets for every field. If natural alignment would introduce an uninitialized padding hole, compilation fails with a suggested explicit ZeroPad[N] field (deterministically zero-initialized on construction and ignored on comparison).
                                                   2. Total Bit-Validity (FromBytes and AsBytes): Every field of a wire struct must inhabit all bit patterns of its width: fixed-width integers, explicit-endian wire integers (u16be, u32be, u64be, i64be, u32le, u64le), fixed byte arrays (ByteArray[N]), or nested wire struct types. bool and sparse enum tags are rejected inside wire struct in favor of total WireFlag8 or WireTag16 wrappers.

13.4 Hardware-Isolated Zero-Copy Sandboxing (Intel MPK/PKRU and Arm POE)

// Length-agnostic, 100% safe SIMD delimiter scanner and XOR checksum over a zero-copy ByteSlice.
// Runs at full hardware width across NEON, AVX2, AVX-512, SVE2, and RVV without `unsafe`!
fn scan_record_delimiters[P: IsaProfile](
    in data: ByteSlice,
    delim: u8,
) -> (u64, u8) eff [Isa[P]] {
    let needle = VVec::splat[P, u8](delim);
    let mut matches_count: u64 = 0;
    let mut xor_acc = VVec::splat[P, u8](0);
    let mut idx: usize = 0;
    let len = data.len();


    while idx != len {
        let mask: VMask[P, u8] = P::active_mask[u8](idx, len);
        let chunk = VVec::load_masked(in data, idx, mask, 0);


        let eq_mask = chunk.simd_eq(needle).and(mask);
        matches_count = matches_count.wrapping_add(eq_mask.count_ones() as u64);
        xor_acc = xor_acc.bit_xor(chunk); // inactive lanes zeroed by load_masked


        idx = idx.wrapping_add(P::lanes[u8](mask));
    }


    (matches_count, xor_acc.reduce_xor())
}

// `@fip` statically proves ZERO heap allocations and ZERO deallocations occur (`eff []` is empty!).
@fip fn balance_left[K: mod copy, V](
    color: Color,
    key: K,
    sink val: V,
    sink left: Option[Box[RbNode[K, V]]],
    sink right: Option[Box[RbNode[K, V]]],
) -> Box[RbNode[K, V]] eff [] {
    match left {
        // Unpacking two owned `Box[RbNode]` values yields two compile-time ReuseSlots paired
        // 1-to-1 by `vesper-opt-egglog` with the two `Box::new` constructors below!
        Some(Box(RbNode {
            color: Color::Red,
            key: lk, val: lv,
            left: Some(Box(RbNode { color: Color::Red, key: llk, val: llv, left: a, right: b })),
            right: c,
        })) => {
            let new_left  = Box::new(RbNode { color: Color::Black, key: llk, val: llv, left: a, right: b });
            let new_right = Box::new(RbNode { color: Color::Black, key, val, left: c, right });
            Box::new_in_caller(RbNode { color: Color::Red, key: lk, val: lv, left: Some(new_left), right: Some(new_right) })
        }
        other_left => Box::new_in_caller(RbNode { color, key, val, left: other_left, right }),
    }
}

                                                   1. 1. First-Class tiled(N) struct (AoSoA + Hot/Cold Segregation):
tiled(N) struct packs N records (8, 16, 32, 64) per contiguous cache-line tile for hot fields while isolating cold fields into a separate page-aligned side array. Disjoint column projections ([T-CallProj]) feed Vesper Vector (VVec) directly without hardware gather instructions, while Lean 4 (vesper-verify-lean) models TiledSeq[T] transparently as Array T:
// Packs 16 entries per tile: `base_offset` (128B) and `batch_crc` (64B) align to 64B L1 cache lines;
// `cold` fields live in a side slab untouched during hot offset/CRC scans.
tiled(16) copy struct LogOffsetEntry {
    hot base_offset: u64,
    hot batch_crc: u32,
    hot byte_len: u32,
    cold producer_id: u64,
    cold compression_codec: u8,
}


fn count_matching_crc[P: IsaProfile](
    in index.{batch_crc}: TiledSeq[LogOffsetEntry],
    target_crc: u32,
) -> u64 eff [Isa[P]] {
    let mut hits: u64 = 0;
    for tile_idx in 0..index.tile_count() {
        let crc_vec = index.load_tile_vec[P, batch_crc](tile_idx);
        let mask    = crc_vec.simd_eq(VVec::splat[P, u32](target_crc));
        hits = hits.wrapping_add(mask.count_ones() as u64);
    }
    hits
}

                                                      * FlatTable[K, V] (Safe SIMD SwissTable): Probes 16-byte h2 control groups in 1–2 instructions via Isa[Baseline128] without unsafe, and exposes get_disjoint_mut for multi-key inout projection.
                                                      * CacheBTree[K, V, B = 16] (SIMD-Searched Cache-Line B+Tree): Branchless SIMD rank search over 16-key cache-aligned nodes using u32 slab-relative indices (50% smaller node pointers, memcpy-relocatable without Pin).
                                                      * ChunkSeq[T] (Transient Radix-Balanced Sequence): Mutates 32-way cache-line chunks in place in O(1) when uniquely owned and freezes in O(1) for zero-copy sharing across Pulse::scope fibers.
                                                      * SlotArena[r, V] and RegionRef[r, T] (Capability-Branded Graph Handles): Generational NodeId[r] keys branded by region r prevent cross-arena index bugs at compile time, while RegionRef[r, T] enables cyclic graphs (CFGs, intrusive LRU caches) safely mediated via inout r.
// Zero-heap-fragmentation log compaction using a 256 KiB lexical Region scratchpad (`Alloc` not used!)
fn compact_log_segment[P: IsaProfile](
    inout out_frame: ByteSlice,
    in raw_segment: ByteSlice,
) -> Result[u32, CompactError] eff [Isa[P], Fail[CompactError]] {
    Region::scoped(256.kib(), |cap scratch| eff [scratch: Region, Isa[P], Fail[CompactError]] {
        let mut latest_by_key = FlatTable::with_region[u64, LogOffsetEntry](in scratch, 4096);
        let mut entries       = TiledSeq::with_region[LogOffsetEntry](in scratch, 4096);


        for batch_hdr in raw_segment.iter_wire_headers[KafkaBatchWireHeader]()? {
            let mark: Watermark = scratch.checkpoint(); // Linear watermark token
            let summary = decode_and_dedup_batch(in scratch, inout latest_by_key, in batch_hdr)?;
            entries.push(summary);
            scratch.rewind(sink mark); // O(1) per-batch temporary reset
        }


        flush_compacted_tiles[P](inout out_frame, in entries)
    })
}

use std::ptr::NonNull;
use std::sync::atomic::{AtomicPtr, Ordering};


/// Cache-line-aligned bump state pointed to by `EvidenceSlot.state_ptr` (`r15` / `x28`).
#[repr(C, align(64))]
pub struct RegionEvidenceState {
    pub bump_cursor: usize,
    pub bump_limit: usize,
    pub virtual_base: NonNull<u8>,
    pub reserved_bytes: usize,
    pub affine_finalizer_head: *mut FinalizerNode,
    pub active_linear_count: u32,
}


#[repr(C)]
pub struct FinalizerNode {
    pub prev: *mut FinalizerNode,
    pub drop_fn: unsafe extern "C" fn(*mut u8),
    pub payload_ptr: *mut u8,
}


impl RegionEvidenceState {
    #[inline(always)]
    pub fn try_bump_aligned(&mut self, size: usize, align: usize) -> Option<NonNull<u8>> {
        let aligned = (self.bump_cursor.checked_add(align - 1)?) & !(align - 1);
        let next = aligned.checked_add(size)?;
        if next > self.bump_limit {
            return None;
        }
        self.bump_cursor = next;
        NonNull::new(aligned as *mut u8)
    }


    #[inline]
    pub unsafe fn rewind_to(&mut self, watermark_cursor: usize) {
        debug_assert_eq!(self.active_linear_count, 0);
        while !self.affine_finalizer_head.is_null()
            && (self.affine_finalizer_head as usize) >= watermark_cursor
        {
            let node = &*self.affine_finalizer_head;
            self.affine_finalizer_head = node.prev;
            (node.drop_fn)(node.payload_ptr);
        }
        self.bump_cursor = watermark_cursor;
    }
}


/// Per-core sharded slab bin (`0` atomics on local fast path; batched remote free stack).
#[repr(C, align(64))]
pub struct SizeClassSlab {
    pub local_free_head: *mut FreeSlot,
    pub remote_free_stack: AtomicPtr<FreeSlot>,
    pub slot_bytes: u16,
    pub owner_core_id: u16,
}


#[repr(C)]
pub struct FreeSlot {
    pub next: *mut FreeSlot,
}


impl SizeClassSlab {
    #[inline(always)]
    pub unsafe fn alloc_local(&mut self) -> Option<NonNull<u8>> {
        if self.local_free_head.is_null() {
            let batch = self.remote_free_stack.swap(core::ptr::null_mut(), Ordering::Acquire);
            if !batch.is_null() {
                self.local_free_head = batch;
            }
        }
        let head = self.local_free_head;
        if head.is_null() {
            return None;
        }
        self.local_free_head = (*head).next;
        NonNull::new(head.cast())
    }
}

16.2 Vesper Pact: Colorless Modal and Effect-Polymorphic Traits
Because Vesper unifies io_uring suspension, checked fallibility (Fail), SIMD ISA profiles (Isa[P]), and lexical arenas (Region) under eff [...] rows, a single trait spans every ownership and execution regime:
// One colorless trait replaces Iterator, LendingIterator, TryStream, and AsyncIterator!
trait Source[r: eff = []] {
    // Modal bound `mod linear` sits at the top of `copy ⊑ affine ⊑ linear`, allowing `Item`
    // to instantiate to `u64` (copy), `RecordBatch` (affine), OR `WriteTxn` (linear)!
    type Item: mod linear;


    fn next(inout self) -> Option[Self::Item] eff [r];
}


// Generic combinator polymorphic over item mode `T: mod linear` AND lexical effect rows `r1`, `r2`:
fn fold_source[S, T, Acc, r1: eff, r2: eff](
    inout src: S,
    sink init: Acc,
    f: fn(sink Acc, sink T) -> Acc eff [r2],
) -> Acc eff [r1 | r2]
where
    S: Source[r1, Item = T],
{
    let mut acc = init;
    loop {
        match src.next() {
            Some(item) => { acc = f(sink acc, sink item); }
            None => break acc,
        }
    }
}

When S is a Vesper PulseTcpFrameSource (r1 = [Net, Cancel]) and f commits a WriteTxn (r2 = [Storage, Fail[IoError]]), the exact same fold_source definition suspends on pooled io_uring fiber stacks while enforcing Section 5's [T-Let] Resumption Frame Condition (m_acc ⊑ res(r1 ∪ r2)).

Vesper Forge unifies compile-time metaprogramming across two lossless rowan CST tiers:
                                                               1. Two-Way Hygiene and the Supply-Chain Anti-Smuggling Law
Every identifier in a Forge CST carries (Symbol, Span, ScopeSet, Option[PreResolvedDefId]):
                                                               * No Local Variable Capture (Scope Sets): Each macro expansion k stamps a fresh ScopeMark(k) onto newly introduced tokens; a local binder let x resolves a reference x if and only if marks(binder) ⊆ marks(reference).
                                                               * No Global Path Hijacking (PreResolvedDefId): Global paths inside quote { @vesper-wire/hash::WireHash::hash_into(...) } resolve their target DefId when the macro package itself is compiled—never requiring downstream callers to add hidden transitive dependencies or $crate::__private re-exports.
                                                               * No Macro Authority Amplification ([T-MacroConfinement]): In Rust, a compromised @derive macro can emit std::net or std::fs calls into an application crate that legitimately holds network/storage permissions. Vesper Forge blocks this attack statically after every macro expansion:
[T-MacroConfinement]
  d = PreResolvedDefId(ident) ∈ expand(M, ast)    origin(d) = M
  ──────────────────────────────────────────────────────────────────────────────
  caps(d) ⊆ macro_emits_effects(M) ∩ capability_ceiling(P_caller)
Macro packages default to macro_emits_effects = [] in Loom.toml. Even when invoked inside a privileged server binary, a pure @derive macro is statically barred from injecting any DefId or handler performing Storage, Net, or Ffi.
// Defined in `@vesper-wire/derive` (compiled to `wasm32-wasip2`, `macro_emits_effects = []`)
#[wasm_macro(derive = WireHash, emits_effects = [])]
pub fn derive_wire_hash(in schema: AdtSchema) -> Result[CstItem, MacroDiag] {
    if schema.nominal_mode == Mode::Linear {
        return Err(MacroDiag::error(
            schema.span,
            "WireHash requires shared `in self`; confirm linear obligation permits hashing",
        ));
    }


    let field_stmts = schema.fields.map(|in f| {
        let fname = f.ident;
        // `@vesper-wire/hash::WireHash::hash_into` is pre-resolved at macro compile time;
        // `h` receives a fresh ScopeMark so a struct field named `h` never collides!
        quote_stmt! {
            @vesper-wire/hash::WireHash::hash_into(in self.$fname, inout h);
        }
    });


    let ty_name = schema.ident;
    Ok(quote_item! {
        impl @vesper-wire/hash::WireHash for $ty_name {
            fn hash_into[H: @vesper-wire/hash::Hasher](in self, inout h: H) eff [] {
                $..field_stmts
            }
        }
    })
}

fn integrate_kinematics[P: IsaProfile](
    inout instances.{pos_x, pos_y, pos_z}: TiledSeq[StaticMeshInstance],
    in instances.{vel_x, vel_y, vel_z}: TiledSeq[StaticMeshInstance],
    dt: f32,
) eff [Isa[P]] {
    let v_dt = VVec::splat[P, f32](dt);
    for tile in 0..instances.tile_count() {
        let px = instances.load_tile_vec[P, pos_x](tile);
        let vx = instances.load_tile_vec[P, vel_x](tile);
        instances.store_tile_vec[P, pos_x](tile, vx.mul_add(v_dt, px));
        let py = instances.load_tile_vec[P, pos_y](tile);
        let vy = instances.load_tile_vec[P, vel_y](tile);
        instances.store_tile_vec[P, pos_y](tile, vy.mul_add(v_dt, py));
        let pz = instances.load_tile_vec[P, pos_z](tile);
        let vz = instances.load_tile_vec[P, vel_z](tile);
        instances.store_tile_vec[P, pos_z](tile, vz.mul_add(v_dt, pz));
    }
}


// Zero-Global-Heap D3D12 Frame Tick (Alloc omitted from eff [...]!):
fn step_and_render_frame[P: IsaProfile](
    inout world.{instances, camera}: GameWorld,
    inout gpu.{device, graphics_queue, swapchain, frame_ring}: D3D12Context,
    in pipelines: IgnisPipelines,
    dt: f32,
) -> Result[FrameStats, GpuError] eff [
    Scope,
    GpuSync,
    Isa[P],
    Ffi[D3D12Agility],
    Fail[GpuError]
] {
    let mut cmd_alloc: ReadyCmdAllocator = gpu.frame_ring.acquire_next_slot();
    Region::scoped(4.mib(), |cap frame| {
        Pulse::scope(|inout s| eff [Scope, Isa[P]] {
            let sim_join = s.spawn(|| eff [Isa[P]] {
                integrate_kinematics[P](
                    inout world.instances.{pos_x, pos_y, pos_z},
                    in world.instances.{vel_x, vel_y, vel_z},
                    dt,
                )
            });
            sim_join.join()
        });
        let mut cmd: CmdList[Graphics, Recording] = gpu.device.begin_cmd_list(inout cmd_alloc);
        cmd.enhanced_tex_barrier(in gpu.frame_ring.vis_buffer, Layout::Undefined, Layout::RenderTarget);
        cmd.dispatch_work_graph(in pipelines.meshlet_cull_and_draw_wg);
        cmd.enhanced_tex_barrier(in gpu.frame_ring.vis_buffer, Layout::RenderTarget, Layout::DirectQueueShaderResource);
        cmd.trace_rays_dxr12(in pipelines.rt_lighting_ser_pso, gpu.swapchain.resolution());
        cmd.enhanced_tex_barrier(in gpu.swapchain.current_backbuffer(), Layout::RenderTarget, Layout::Present);
        let closed_cmd: CmdList[Graphics, Closed] = cmd.close();
        let fence_ticket: InFlightFrame = gpu.graphics_queue.submit_and_signal(sink closed_cmd, sink cmd_alloc);
        gpu.frame_ring.park_in_flight(sink fence_ticket);
        gpu.swapchain.present_tearing_allowed()
    })
}

// crates/vesper-ignis/src/lib.rs
use rustc_hash::FxHashMap;
use smol_str::SmolStr;


#[derive(Clone, Copy, Debug, PartialEq, Eq, Hash)]
pub struct RgResourceId(pub u32);


#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum BarrierSync {
    None,
    Draw,
    PixelShading,
    DepthStencil,
    ComputeShading,
    Raytracing,
    Copy,
}


#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum BarrierAccess {
    NoAccess,
    ShaderResource,
    RenderTarget,
    DepthStencilWrite,
    UnorderedAccessReadWrite,
}


#[derive(Clone, Copy, Debug, PartialEq, Eq)]
pub enum BarrierLayout {
    Undefined,
    Present,
    RenderTarget,
    DepthStencilWrite,
    DirectQueueShaderResource,
    DirectQueueUnorderedAccess,
}


#[derive(Clone, Debug, PartialEq, Eq)]
pub enum EmittedD3D12Barrier {
    Texture {
        resource: RgResourceId,
        sync_before: BarrierSync,
        sync_after: BarrierSync,
        access_before: BarrierAccess,
        access_after: BarrierAccess,
        layout_before: BarrierLayout,
        layout_after: BarrierLayout,
    },
    IntraListFenceSignal { pass_idx: usize, sync_before: BarrierSync, fence_val: u64 },
    IntraListFenceWait { pass_idx: usize, sync_after: BarrierSync, fence_val: u64 },
}


#[derive(Clone, Copy, Debug)]
struct TrackedSubresourceState {
    last_writer_pass: Option<usize>,
    last_sync: BarrierSync,
    last_access: BarrierAccess,
    layout: BarrierLayout,
    is_read_only_since_write: bool,
}


#[derive(Default)]
pub struct IgnisBarrierCompiler {
    states: FxHashMap<RgResourceId, TrackedSubresourceState>,
    next_fence_val: u64,
}


impl IgnisBarrierCompiler {
    pub fn register_resource(&mut self, id: RgResourceId, initial_layout: BarrierLayout) {
        self.states.insert(
            id,
            TrackedSubresourceState {
                last_writer_pass: None,
                last_sync: BarrierSync::None,
                last_access: BarrierAccess::NoAccess,
                layout: initial_layout,
                is_read_only_since_write: true,
            },
        );
    }


    pub fn transition_texture(
        &mut self,
        pass_idx: usize,
        id: RgResourceId,
        sync_after: BarrierSync,
        access_after: BarrierAccess,
        layout_after: BarrierLayout,
        is_write: bool,
        out: &mut Vec<EmittedD3D12Barrier>,
    ) -> Result<(), SmolStr> {
        let st = self
            .states
            .get_mut(&id)
            .ok_or_else(|| SmolStr::new("unregistered render-graph texture"))?;
        if !is_write && st.is_read_only_since_write && st.layout == layout_after {
            return Ok(());
        }
        if let Some(writer_idx) = st.last_writer_pass {
            if pass_idx.saturating_sub(writer_idx) >= 3 && st.layout == layout_after {
                self.next_fence_val += 1;
                let val = self.next_fence_val;
                out.push(EmittedD3D12Barrier::IntraListFenceSignal {
                    pass_idx: writer_idx,
                    sync_before: st.last_sync,
                    fence_val: val,
                });
                out.push(EmittedD3D12Barrier::IntraListFenceWait {
                    pass_idx,
                    sync_after,
                    fence_val: val,
                });
            } else {
                out.push(EmittedD3D12Barrier::Texture {
                    resource: id,
                    sync_before: st.last_sync,
                    sync_after,
                    access_before: st.last_access,
                    access_after,
                    layout_before: st.layout,
                    layout_after,
                });
            }
        } else if st.layout != layout_after {
            out.push(EmittedD3D12Barrier::Texture {
                resource: id,
                sync_before: st.last_sync,
                sync_after,
                access_before: st.last_access,
                access_after,
                layout_before: st.layout,
                layout_after,
            });
        }
        st.last_sync = sync_after;
        st.last_access = access_after;
        st.layout = layout_after;
        st.is_read_only_since_write = !is_write;
        if is_write {
            st.last_writer_pass = Some(pass_idx);
        }
        Ok(())
    }
}

## Result and proof boundary

The producer binds the actual checked pure island through the shared admission
helper, interns indexed typed terms directly and constructs Math RecExpr nodes
without formatting/parsing source s-expressions or interning source names into
egg symbols. A bottom-up prefix retains all six direct constant-fold cases as
explicit rules 19–24 with child congruence. Checked overflow keeps its operator;
wrapping folds retain the actual kind's modulo semantics, including high U64.
Only reachable folded constants outside Math::Num(i64)'s range select the
explicit witnessed fold-only profile. Resource failure never selects that path.

The 18 actual forward appliers are wrapped to record successful stable rule IDs
and bounded substitutions. Fixed-limit searching checks the frozen pattern's
concrete-node assignment envelope before asking egg for at most 128 matches.
Raw original graph nodes are translated only after checking backward child IDs
and source variable inventory bounds. Canonical classes/find select search
data, but cannot establish an equality.

A bounded rank forest retains explicit proof IDs for every producer merge.
Iterative paths emit earlier-only symmetry/transitivity records; congruence
uses corresponding child equalities. Guarded erasure waits for a real earlier
equality to a source-bound variable/constant leaf when the erased term is not
already such a leaf. Unavailable guards cannot bootstrap their own totality.
The final proof connects the original source root through the fold prefix to
the actual extracted root. The independent checker redoes the reasoning.

Original intrinsic callee expressions/spans and output expansion checks come
from the shared bounded builder. Candidate value spans use the original root
span; actual admitted same-operator callee templates retain their own spans.
The boxed proposal allocation is prepaid on the same move-only budget before
handoff. No intermediate AST or partially witnessed prefix is installed.

## Completion and resources

Egg explanations remain disabled: neither TreeTerm flattening nor egg's debug
explanation expansion/checker is used. Accepted search completion is ordinary
Saturated or the distinct published MinimumRootComplete case: the actual root
contains an in-profile Num/Input leaf, attaining AstSize's global lower bound 1.
The exact private hook marker, current leaf and absence of recorded failure
are all checked. This stops cyclic annihilator/cancellation classes after the
objective is met while retaining the full captured proof/checker requirement.
Arbitrary hook errors and iteration/node/time/resource stops still refuse the
whole attempt; a minimum leaf never clears or reclassifies a sticky failure.

Admission, prefix, search, proof construction, candidate building and final gate
share one cumulative budget. Working vectors reserve fallibly with full growing
capacity requests charged. Graph credits grow proportionally and prepay full
replacement capacity before raw-node growth, including persistent `512 * c` and
cumulative `128 * c * c` cleanup envelopes. Search charges possible failed assignments
as well as successful capped output; proof paths and quadratic closure scans
are charged before execution. Expanded AST occurrences, depth and identifier
bytes are checked before materialization by the shared builder.

The 2048 raw-node, 8 iteration, 128 match and 4096 recorded-application bounds are
private ceilings, not promised admission sizes. Composite metadata/work limits
can refuse substantially earlier. No caps were increased or reset to obtain a
candidate. Barrier is reserved for initial unsupported typing/syntax; any later
failure preserves the entire original admitted island without child retries.

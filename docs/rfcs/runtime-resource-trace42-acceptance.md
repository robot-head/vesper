## Authored checks

Seventeen independent integration tests exercise actual parser/checker output, then the real reference `Runtime`. Fixtures cover selected empty linear structs, empty constructor names and record construction, terminal destructuring, helper/sink identity transfer, borrowing, structural wrappers, copy-field projection, tuple transfer, shadowing, distinct resources minted at one helper site, two selected kinds and unselected-type isolation. A separate qualified `Other::Ticket` fixture guards against mistaking an unselected enum constructor for a selected struct by its basename. Both Runtime IR optimization settings execute; a smaller actual AST optimizer off/on × IR optimizer off/on matrix checks repeated mints and failed match probes with exact original pattern provenance. This is four reference-interpreter configurations, not the eight-way evaluator/native resource oracle.

The match fixture intentionally probes a tuple's Ticket pattern successfully before its boolean component fails, then selects another arm. Only the selected owning pattern may consume, at its own original byte span. Internal handler fixtures separately cover an owning return pattern and a borrowed operation-handler constructor pattern. Borrowed patterns and probes must not consume. An operation clause with two owned atom patterns tests whole-clause capacity admission; a late actual clause-pattern mutation must fail before either earlier atom is consumed. Expected byte positions come from the current canonically formatted source, not fixed offsets from an earlier formatting pass.

Carrier mutation controls first parse and check valid source. They then alter the actual cloned World's executable expression routing while retaining genuine spans: route a record's second field through the first value, route the second close through the first binding, alias both elements of one terminal pattern, duplicate a returned owner, or return an already consumed owner. The real Runtime must reject those actual carriers and preserve the exact event prefix and live distinct owner. These controls do not fabricate identities or modify event lists.

Other tests cover ordinary unobserved values without identities; completed returned owners remaining visible in residuals; missing, foreign-instance and prior-run entry carriers; corrupted real carrier metadata; repeat epochs and immutable prior observer snapshots; zero/exact event and resource capacities; total lifetime mint capacity including consumed history; all-or-nothing terminal pattern batches; returned/entry traversal limits; real runtime-error and bounded fuel-sweep prefixes; invalid type selections; cross-World configuration refusal/revalidation; reconfiguration refusal; and explicit traced external-session refusal. No successful cleanup events are inferred on error or fuel exhaustion. Completed returned ownership is not treated as an exhaustion theorem.

Actual boundary shape controls pass a real ordinary Ghost value to the checked Ticket relay, and mutate a valid checked `(Ticket, Ghost)` return so both output elements route to Ghost. The second case would evade a selected-carrier-only walk; declared result validation must refuse while preserving the actual Ticket mint and residual. All positive boundary types in this target are monomorphic scalars, unit, tuples or nongeneric ADTs. No generic boundary admission is presumed.

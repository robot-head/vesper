# Vesper website design

The site helps a systems programmer decide whether Vesper’s ownership and effect checks suit a workload. The landing page traces one append call through the three fields of the broker. Readers can vary the configuration value to see its effect on the index.

The Rust comparison follows three API decisions. Each panel explains the corresponding Rust idiom, the Vesper rule, and a failure case from the checker fixtures. The source explorer includes the complete programs from the repository. The compiler section distinguishes checking, execution, and proofs about extracted models.

The site uses the canonical prism mark, Space Grotesk for headings, Inter for text, and JetBrains Mono for code and figure labels. Amber connects the primary action and the updated field values. Source highlighting retains the ownership, mutation and effect colors. The Dusk and Dawn themes share the same layout and use the same field names and permissions.

# Vesper website design

The site helps a systems programmer decide whether Vesper’s ownership and effect checks suit a workload. The landing diagram shows the three fields from `examples/projections.ves`. Its separated layers represent access permissions. The program supplies the actual field names and parameter modes.

The Rust comparison follows three API decisions. Each panel explains the corresponding Rust idiom, the Vesper rule, and a failure case from the checker fixtures. The source explorer includes the complete programs from the repository. The compiler section distinguishes checking, execution, and proofs about extracted models.

The site uses the canonical prism mark, Space Grotesk for headings, Inter for text, and JetBrains Mono for code and figure labels. Amber connects the primary action and the field diagram. Source highlighting retains the ownership, mutation and effect colors. The Dusk and Dawn themes share the same layout, and the technical plate keeps its dark plotting surface in both themes.
